# Fluxo: genérico

Para histórias que não têm fluxo próprio. É menos guiado, então a confirmação
com o usuário pesa mais.

## 1. Completar a spec
Marque cada campo da spec como ✅ encontrado (com trecho), 🟡 inferido ou
❌ faltando. Pergunte os 🟡 e ❌ de uma vez.

## 2. Planejar
Liste os arquivos que pretende criar ou alterar e por quê, e mostre ao usuário
antes de começar. Leia só esses arquivos; se precisar de mais, diga o que e por
quê.

## 3. Implementar
Siga o AGENTS.md. Não refatore código que não faz parte da história.

## 4. Testes
Testes unitários para cada regra da spec e TAAC quando a história mexer em
comportamento exposto.

## 5. Registrar
No resumo final, diga se esse tipo de história parece recorrente. Se for, vale
criar um fluxo próprio para ele.

Volte para o passo 6 do SKILL.md.
